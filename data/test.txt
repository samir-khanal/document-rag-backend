Palm Mind AI is evaluating a backend RAG system. The system needs to ingest documents, extract their text, divide the text into meaningful chunks, generate embeddings, and store those embeddings in a vector database.

The document ingestion API should support different chunking strategies. Fixed-size chunking should divide the document according to a predefined character limit. Recursive chunking should try to preserve meaningful boundaries such as paragraphs, lines, sentences, and words.
